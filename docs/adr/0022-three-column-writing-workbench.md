# 三栏写作台：左设定 · 中正文 · 右对话

2026-10-21 提议并接受。

状态：已接受。本决定在纸墨视觉之上，把作品内主壳从「流程脊四阶段」改为三栏写作台；聊天重新成为右栏主表面。ADR-0021 关于取消 IDE 四区、纸墨唯一外壳、运行合并为侧页的决定仍然有效；其中「作品内主导航为四个阶段」和「聊天不出现在新界面」由本决定取代。

## 决定

打开作品后的主界面为三列：

1. **左栏（材料）**：人物、背景（世界观）、故事前提/大纲摘要、本章蓝图摘要等设定资料；可收起。不再以流程脊四阶段作为主导航。
2. **中栏（正文）**：当前章编辑与章节切换；打开作品默认落到下一章待写或最近编辑章，不因设定未填完而强制停在设定页。
3. **右栏（AI 对话）**：常驻写作助手对话框。工作流运行进度并入右栏「运行」子页（或对话内任务卡片）；顶栏运行胶囊仍可打开该子页。

成稿路径：对话触发写章/修稿工作流后，结果以**整章候选草稿版本**呈现；作者点「采用」后该候选成为当前可编辑草稿，「丢弃」则保留原状并归档/丢弃候选。不采用光标选区直接覆盖。ADR-0008 不变：改结构化事实仍走 propose / 工作流 seam。

沉浸写作隐藏左右栏；窄屏允许收起左或右栏。设定、架构、蓝图等独立页可暂时保留为次级入口，第一期不要求一次删光。

## 原因

流程脊把精力耗在填系统上；隐藏聊天又切断了接近直连模型的主路径。三栏写作台保留纸墨观感，同时让中栏出字、右栏对话驱动写稿成为默认体验。

## 后果

- `StageSpine` 不再作为作品主壳；由材料栏与三列布局替代（旧组件可暂留供测试或次级入口，直至清理）。
- `AIPanel` / `agent-store` / agent 工具重新挂到右栏；`app-no-chat` 类验收改为「打开作品可见对话；书房默认无聊天」。
- MCP 仍不因启动自动连接；首次进入对话初始化内置工具与 Skills，MCP 仍由设置或助手菜单显式开启。
- 写章主路径为对话 + 候选采用；蓝图页「写作此章」等按钮可并存，不作为唯一入口。
- 隐藏 AI 聊天的需求文档（`req-hide-ai-chat.md`）对「界面不得出现聊天」的验收不再适用；以本 ADR 为准。
